# Mein Training

Statische Trainings-Web-App mit drei Oberkörpereinheiten, einem Beintag, Organizer,
Pausentimer, Schritten und lokal gespeicherten Trainingswerten.

## GitHub Pages

1. Ein Repository namens `mein-training` unter dem gewünschten GitHub-Konto anlegen.
2. Die Dateien aus dem ZIP entpacken und direkt ins Stammverzeichnis des
   Repositorys hochladen. `index.html` muss im Stammverzeichnis von `main` liegen.
3. Unter **Settings → Pages → Build and deployment** die Quelle **Deploy from
   a branch** einstellen und **main → / (root)** auswählen. Speichern.
4. Sobald der Build erfolgreich ist, die HTTPS-Adresse aus **Settings → Pages**
   öffnen.

Für GitHub Free muss das Repository öffentlich sein. Das Paket enthält den
statischen Trainingsplan. Lege persönliche JSON-Backups ausschließlich lokal ab.

## iPhone

Den veröffentlichten Link in Safari öffnen. Über **Teilen → Zum Home-Bildschirm**
die Option **Als Web-App öffnen** aktivieren und auf **Hinzufügen** tippen.

Für die Datenübernahme die App über das Symbol auf dem Home-Bildschirm öffnen
und im **Organizer → Backup importieren** die exportierte JSON-Datei auswählen.
Die Werte liegen im lokalen Speicher der geöffneten App. Die alte URL hat
einen eigenen Speicherbereich.
